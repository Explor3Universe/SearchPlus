# Privacy

SearchPlus is a set of Markdown instructions (`skills/searchplus/SKILL.md` and its reference files) for AI agents. It contains no code, no servers and no analytics.

- SearchPlus itself does not collect, store or transmit any data.
- When an agent follows SearchPlus, it uses the agent's own web search and page-reading tools. Those requests are governed by the privacy policy of the agent and of the tools you use with it.
- The research log the skill may write is a local file on your machine, in a temporary folder or one you choose.

Questions: [open an issue](https://github.com/Explor3Universe/SearchPlus/issues).
